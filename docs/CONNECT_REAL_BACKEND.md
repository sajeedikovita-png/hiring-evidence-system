# Connect the real backend (Step 1 + 2 of the real build)

This turns the app from **demo/mock mode** into the **real backend**: real database,
real login, real per-account data. Your app is already pointed at your Supabase project
(`.env.local`), so once the database is set up and you log in, the app shows REAL data.

> Time: ~10 minutes, all in your browser. No password sharing needed.
> You'll do this in the **Supabase dashboard** (https://supabase.com/dashboard).

## Step 1 — Create the database tables

1. Open your project in the Supabase dashboard.
2. Left sidebar → **SQL Editor** → **New query**.
3. Open the file **`supabase/schema.sql`** from this repo, copy ALL of it, paste into the
   editor, and click **Run**.
4. ✅ Expected: "Success. No rows returned." This created 12 tables + security rules.
   (Check **Table Editor** — you should now see `companies`, `job_roles`, `candidates`,
   `evidence_reports`, etc.)

---

## Step 2 — Create your login account

1. Left sidebar → **Authentication** → **Users** → **Add user** → **Create new user**.
2. Enter an **email** and a **password** you'll remember (write them down).
3. Turn ON **Auto Confirm User** (so you can log in immediately, no email step).
4. Click **Create user**.

That's it — no UID to copy. The bootstrap in Step 3 finds your account by this email.

---

## Step 3 — Link your account + load starter data

1. Open the file **`supabase/bootstrap.sql`** from this repo.
2. At the top, edit the **one** line marked `<< REPLACE`:
   - `v_email` → the **same email** you used to create your login in Step 2.
3. Copy the whole edited file → SQL Editor → **New query** → paste → **Run**.
4. ✅ Expected: "Success" with a notice `Bootstrap complete...`. This created your company
   (**Northstar Digital**), linked your login to it, and added one job + two candidates +
   one evidence report so the app isn't empty.

> Safe to run: it finds your account by email automatically, and if you run it twice it stops
> with a clear message instead of creating a duplicate company.

---

## Step 4 — Log in and see real data

1. Make sure the app is running: `npm run dev` (it serves at http://localhost:3000).
2. Go to **http://localhost:3000/login**.
3. Sign in with the **email + password** from Step 2.
4. ✅ You land on the dashboard showing **real data from your database** — 1 job,
   2 candidates, 1 completed report. Open the Frontend Developer candidates → open
   **Priya Shah** → you'll see the evidence report served from Supabase. Record a decision
   with a reason → it saves to the real database.

## Notes & troubleshooting

- **Dashboard is empty or shows a connection error after login:** the most common cause is
  the `recruiter_profiles` row — it must have `status = 'active'` and `user_id` equal to
  your Auth user UID. Re-check the UID you pasted in Step 3.
- **You see "Authenticated user is required":** you're not logged in. Start at `/login`.
- **To go back to demo/mock mode** (e.g. to show the full 3-role demo): rename `.env.local`
  to `.env.local.off` and restart `npm run dev`. The app falls back to the built-in mock
  data. Rename it back to return to the real backend.
- **Adding more data:** for now, add rows via the Supabase Table Editor or by extending
  `bootstrap.sql`. A real "create job / add candidate" UI is a later step.
